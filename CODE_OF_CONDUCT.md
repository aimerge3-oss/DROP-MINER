# Contributor Covenant Code of Conduct

## Our pledge
We make participation in DROP MINER development a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, nationality, race, religion, or tech stack choice (yes, even Svelte fans).

## Standards
Positive: constructive reviews, empathy, assuming good faith, critiquing code not people. Unacceptable: sexualized language, trolling, personal attacks, publishing others' private info, doxxing, sustained disruption.

## Enforcement
Report issues to the repository owner privately. Complaints are reviewed fairly; moderators may edit/remove comments or ban repeat offenders.
